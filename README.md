# 👥 HR Analytics Dashboard | Power BI

An interactive **HR Analytics Dashboard** built using **Power BI** to analyze employee performance, workforce distribution, attrition trends, and key HR metrics. This project helps organizations make data-driven decisions related to employee retention and workforce management.

## ▶️ How to Use

1. Clone this repository.
2. Open **`HR Performance and Retention Dashboard.pbix`** in **Power BI Desktop**.
3. If required, reconnect the Excel dataset.
4. Explore the dashboard using the available filters and slicers.
